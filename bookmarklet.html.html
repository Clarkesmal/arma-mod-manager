Mod Manager Bookmarklet
Scrape Workshop pages while logged in — no proxy needed
One-time setup
1
Enter your Mod Manager URL
Paste your GitHub Pages URL below so the bookmarklet knows where to send the data.
2
Make sure your bookmarks bar is visible
In Chrome or Edge press Ctrl+Shift+B to show the bookmarks bar if it's hidden.
3
Drag this button to your bookmarks bar
Click and drag the button below up to your bookmarks bar and release it there.
📋 Send to Mod Manager
↑ Drag this button up to your bookmarks bar
⚠ Enter your GitHub Pages URL above first, then drag the button
Daily use
1
Go to a Workshop mod page
Browse to reforger.armaplatform.com/workshop, click through the age verification, and open any mod page.
2
Click the bookmarklet
Click Send to Mod Manager in your bookmarks bar. It reads the page you're already on.
3
Your Mod Manager opens with data pre-filled
A new tab opens with the Mod Manager already populated with the mod name, ID, version, size, developer, and dependencies. Just fill in the test details and save.
How it works
The bookmarklet runs as JavaScript on the Workshop page itself — no proxy, no CORS issues, no age gate problems. Since you're already logged in and on the page, it can read everything directly. It packages the data into a URL and opens your Mod Manager with the fields pre-populated.
